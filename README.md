# Linear Algebra Animations

Interactive, self-contained HTML visualizations for linear algebra instruction by David Stroup.

Open `index.html` for the collection, or explore `row-reduction/echelon-forms.html` directly.

These pages can be served with GitHub Pages and embedded in Brightspace using an iframe.

## Gram–Schmidt in 3D

Open [`gram-schmidt/3d-orthogonalization.html`](gram-schmidt/3d-orthogonalization.html) for a self-contained, rotatable 3D orthogonalization animation with seven guided steps, visible vector projections, and an optional orthonormalization step. No external JavaScript dependencies are required.
